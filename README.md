# Ultimate Stadium

An Overwatch Stadium build randomizer inspired by [Ultimate Bravery](https://www.ultimate-bravery.net/). Select a hero or hit **Random Hero** to get a randomized set of powers and items for your next Stadium run.

---

## How It Works

- Select a hero from the grid or click **Random Hero**
- A random set of 4 powers and 6 items will be generated for that hero
- Maximum of 1 Gadget item per build
- Click **Copy Build** to copy the build to your clipboard
- Click the reroll button next to the hero name to generate a new build for the same hero
